# Kol Platform – Web & Mobile Backend

Kol Platform is a unified backend system designed to serve both **web** and **mobile** applications.  
It is built using **Spring Boot** and follows clean architecture principles to ensure scalability, security, and maintainability.

The system provides secure authentication, role-based authorization, and RESTful APIs to support multiple client platforms from a single backend.

---

## 🚀 Features

- Unified backend for **Web & Mobile** clients
- Secure **JWT-based authentication**
- **Role-Based Access Control (RBAC)**
- RESTful API architecture
- MongoDB for flexible and scalable data storage
- Clean, layered architecture (Controller → Service → Repository)
- Ready for cloud deployment and future microservices migration

## 🔐 Authentication & Authorization

- Uses **JWT (JSON Web Token)** for stateless authentication
- Secure login and token-based access
- Role-based authorization for protected endpoints
- Supports multiple client types (web & mobile) using the same security flow

---

## 📡 API Design

- RESTful endpoints following best practices
- JSON-based request/response
- Designed to be easily consumed by:
  - Web applications
  - Android / iOS mobile applications
